# Python CLI Todo

一个基于 Python 的命令行 Todo 应用。

## 功能

- 添加任务
- 查看任务
- 完成任务
- 删除任务
- JSON 文件持久化
- 基本参数校验
- 异常处理

## 使用

添加任务：
python todo.py add "学习 Python"

查看任务：
python todo.py list

完成任务：
python todo.py done 1

删除任务：
python todo.py delete 1

## 技术

- Python
- sys.argv
- pathlib
- JSON
- 函数
- 异常处理
